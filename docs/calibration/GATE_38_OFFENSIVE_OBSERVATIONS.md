# Gate 38: Offensive Observations

Review date: 2026-07-30

Status: **PASS; SHADOW ONLY**

The setter ranks attack options from perceived hitter positions and approach
windows. The selected hitter then reads the set repeatedly and observes noisy
opponent positions based on anticipation, court vision, decision-making, and
composure.

Shot selection searches the largest gap in those perceived positions. It never
receives `DefensivePlan`, exact opponent coordinates, or a precomputed true
best target. Authoritative approach and contact facts remain resolver evidence
and cannot alter the recorded decision after the observation is fixed.

The development overlay draws the perceived approach, repeated set reads,
observed opponent markers, selected contact, and perceived shot target.
