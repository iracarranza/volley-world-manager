# Part 6 — Guided Exercises

Practice, in an order that builds. Nothing here is required to understand the
rest of the book, and everything here is required to be able to *use* it.

   treasure hunt to a full visual validation ladder
2. [Beginner Project Ladder](02_beginner_project_ladder.md) — the migration
   reconstructed as a teaching sequence, **historical, not the roadmap**

## Prerequisites

- [Part 1](../part_01_project/README.md) and [Part 3](../part_03_workflow/README.md)
- Individual exercises name their own

## Two rules

1. **One exercise at a time, and commit only after validation.**
2. **A success criterion you cannot fail is not one.** Where an exercise says a
   test should fail if something were inserted, insert it and watch.
