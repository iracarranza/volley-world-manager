# Part II — Interface and Visual Architecture

This part explains how VWM turns Godot UI primitives into its desk/paper/sticker visual language.

The goal is not merely to identify files. By the end of the part, you should be able to trace a visible control from its scene/component through Theme data and GDScript behavior, and understand which visual systems are authored in the editor versus built/rendered at runtime.
