# Part II — Interface and Visual Architecture

This part explains how VWM turns Godot UI primitives into its desk/paper/sticker visual language.

By the end, you should be able to trace a visible control from screen/component through Theme data and GDScript behavior, distinguish editor-authored from runtime-built UI, and debug the rendering layer without making presentation authoritative over game state.
