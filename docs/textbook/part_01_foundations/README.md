# Part I — Reading and Writing VWM

This part gives you enough Godot/GDScript footing to read the rest of the book without requiring a separate beginner course first.

It is intentionally project-facing. Later chapters continue teaching and reminding you of the language/engine in context.

## Chapters

1. [What VWM Is and How the Repository Is Organized](01_project_and_repository.md)
2. [Using the Godot Editor](02_using_the_godot_editor.md)
3. [GDScript: The Language Needed to Read VWM](03_gdscript_for_vwm.md)
4. [Godot's Object Model: Nodes, Scenes, Resources, and Signals](04_godot_object_model.md)
5. [Tracing Code Through VWM](05_tracing_code_through_vwm.md)
6. [Making a First Safe Change](06_first_safe_change.md)

After this part, you should be able to open a source file named by the textbook, read ordinary function signatures/control flow, distinguish the main Godot object/file kinds, trace a behavior across files, and make a bounded change with a clear proof plan.
