# Management Intelligence — Implementation Gaps

## Priority A — complete existing causal loops

### A1. Learned tactical preferences

The largest structural absence. Natural system-fit is rating-derived, but the designed learned offsets for coordinates, tempos, loci and postures do not exist as an authoritative manager-trainable layer.

### A2. Planner decomposition and fit

Presets need to become concrete asks in exactly the state space learned preferences use. Fit must be per ask so the player knows what to train.

### A3. Match adaptation certification

Exposure/read infrastructure and setter response exist. The full concentration -> defensive adaptation -> offensive counter-response chain needs controlled proof over meaningful samples and both sides.

### A4. Tempo-specific pair familiarity

General `PairFamiliarity` exists. The training design needs relationship-specific tempo comfort without converting the general pair number into an overloaded universal chemistry score.

## Priority B — make knowledge age and belong to people

### B1. Scouting freshness

Old observations must widen again. Otherwise scouting becomes permanently solved.

### B2. Scout report history

Persist what each scout claimed so disagreement becomes judgment the manager can evaluate rather than flavor noise.

### B3. Regional scouting knowledge

Use existing region facts as actual epistemic inputs rather than biography-only data.

### B4. Demonstration-gated discoveries

Rare traits and advanced signature vocabulary should be compatible with "you know it because you saw it" rather than ordinary narrowing bands.

## Priority C — player-facing legibility

### C1. Derived style surface

Generate style descriptions only from supported causal behavior/evidence. No new play-style truth.

### C2. Designed-vs-observed training visualization

Only after learned preferences and practice execution exist, show where the actual Volis drift from the manager's demonstrated play.

### C3. Explain opponent adaptation

The manager eventually needs evidence that an opponent has learned a pattern without exposing hidden exact simulator values.

## Explicit non-gaps

Do **not** create these as fixes:

- generic `adaptation` attribute;
- generic `team chemistry` replacement for pair/slot-specific knowledge;
- global `play familiarity` bar;
- stored `play_style` archetype;
- scouting that writes estimates onto the Voli;
- direct "scouted play effectiveness" penalty;
- training that raises ability when the intended quantity is comfort;
- Play Designer trajectories becoming rally authority.

## Interaction with M9

Canonical M9 now establishes that all 39 selectable tactical families have real
causal paths. This packet deliberately does not compete with that work.

The post-M9 recensus found that the gaps above remain gaps. Learned preference
can attach to the certified authored ask / first-mediator seams rather than to
pre-M9 dead or partial paths, but no such state or consumer was added during
integration. Implementation still requires its own authorized milestone.
