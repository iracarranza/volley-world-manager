# M9 — Certification

## Per-instruction gate

For each selectable tactic, construct paired fixtures differing only in the instruction under test.

Require:

1. source state otherwise identical;
2. RNG identical/fixed where applicable;
3. instruction reaches the intended simulation consumer;
4. first divergence occurs at the governed decision boundary;
5. divergence propagates through existing physical authority;
6. source state remains immutable;
7. no presentation/diagnostic value is gameplay authority;
8. symmetry holds where applicable.

## Invariants

- tactic ≠ outcome label;
- tactic ≠ fabricated feasibility;
- tactic ≠ replacement ball;
- intended target ≠ guaranteed endpoint;
- instruction changes probability/choice/geometry only where current semantics authorize it;
- one contact → one authoritative outgoing ball remains intact.

## Observation set

After causal certification, measure aggregate consequences as observations: contacts/rally, serve error/ace, reception quality, kill, block touch/stuff, dig, rally length, side-out where instruments already exist. Only an existing explicit acceptance bound turns a value into a gate.

## Regression set

Re-run the then-current canonical side-out probe, contact/ball authority probes affected by M8, movement/continuity probes, and full foundation suite. Read FAIL lines and targeted invariants; check-count movement alone is not regression evidence.

## Closure table

M9 handoff must list every selectable instruction and final class. `UNKNOWN`, unexplained `PARTIAL`, or knowingly false player agency prevents closure.
