# M9 — Work Units

Execute after census; order by dependency, not UI order.

## T0 — Freeze census

Eliminate `UNKNOWN`. Record exact source→storage→consumer chains. Remove stale prose claims disproved by source.

## T1 — Stored-only / dead boundary

For each `STORED_ONLY` selectable instruction:
- if governing semantics already exist in authority docs/current sibling implementation, wire the existing semantics into the proper decision boundary;
- otherwise STOP only for that semantic decision after completing independent units. Do not invent an effect.

For `DEAD` controls, remove/disable player-facing choice rather than preserving false agency.

## T2 — Responsibility and target causality

Close instructions whose first effect should be responsibility, target, read, or intended recipient. Verify intended target ≠ physical endpoint/interceptor.

## T3 — Position/movement causality

Close instructions whose effect is starting shape, responsibility geometry, movement destination, or timing. Reuse live-position/traversal authority. No teleporting tactical shapes.

## T4 — Action-choice causality

Close instructions that govern action selection only after perception/responsibility/feasibility inputs are established. Tactic may bias an allowed choice; it may not legalize an impossible action.

## T5 — Contact/trajectory consequences

Verify downstream realised differences are consequences of T2–T4 and existing physical/contact authority. No tactic-owned replacement trajectory or outcome.

## T6 — Symmetry

Apply/certify equivalent home/opponent path where semantics are symmetric. Record intentional asymmetry only when governed.

## T7 — Integration certification

Run paired causal probes, canonical rally/authority probes, full suite, and observational distributions. Update milestone/debt docs from measured state.
